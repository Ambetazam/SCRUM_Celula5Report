# Design the Relational Database Model

## Objective

Design the five-table relational database that supports weekly menu planning, recipes, ingredients, pantry quantities, and shopping-list generation.

## Tasks

* Identify the entities required by the system.
* Define the five database tables.
* Define primary keys.
* Define foreign keys.
* Define cardinalities.
* Define relevant attributes.
* Define appropriate SQL data types.
* Identify integrity constraints.
* Produce the relational model.
* Prepare the initial SQL schema.

## Acceptance Criteria

* [ ] Exactly five principal tables are proposed.
* [ ] Primary keys are defined.
* [ ] Foreign-key relationships are defined.
* [ ] Relationships support weekly menu planning.
* [ ] Relationships support recipe ingredients.
* [ ] The model supports shopping-list generation.
* [ ] The model supports pantry quantities.
* [ ] The relational diagram is understandable.
* [ ] SQL schema can be executed without structural errors.
