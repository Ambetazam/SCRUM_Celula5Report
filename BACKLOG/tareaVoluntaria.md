# Connect Tables and Illustrations to the Table of Contents

## Objective

Configure the Microsoft Word document so that all tables and illustrations used in the **Informe de Requisitos** are correctly identified and automatically reflected in their corresponding lists.

## Tasks

* Review all tables currently included in the document.
* Review all illustrations/figures included in the document.
* Verify that every table has a proper table caption.
* Verify that every illustration has a proper figure caption.
* Use Word's automatic caption functionality instead of manually typed titles.
* Configure the **Lista de tablas**.
* Configure the **Lista de ilustraciones**.
* Update all fields after making the changes.
* Verify that the page numbers are automatically generated.
* Verify that the entries correspond to the correct tables and illustrations.
* Check that the formatting is consistent with the rest of the document.

## Acceptance Criteria

The task is considered complete when:

* [ ] Every table has a numbered caption.
* [ ] Every illustration has a numbered caption.
* [ ] The Lista de tablas is automatically generated.
* [ ] The Lista de ilustraciones is automatically generated.
* [ ] Page numbers are automatically generated.
* [ ] No table or illustration is missing from its corresponding list.
* [ ] No obsolete entries remain.
* [ ] The document can be updated automatically if the position of a table or illustration changes.
* [ ] The final document maintains the established APA-oriented formatting.
