##  Branch Conventions

	feature/<short-name>
	fix/<short-name>
	docs/<short-name>
	test/<short-name>
	chore/<short-name>

### Examples:

	feature/weekly-planner
	feature/shopping-list
	docs/report-indexes
	database/relational-model
	test/menu-planning

##  Commit Convention

	feat: new functionality
	fix: bug correction
	docs: documentation
	test: tests
	refactor: code restructuring
	chore: maintenance
	style: formatting only


### Examples:

	feat: implement weekly menu endpoint
	docs: update requirements report
	test: add shopping list validation
	fix: correct pantry subtraction


## Scrum Master responsibilities

	The Scrum Master should:

	Maintain the GitHub board.
	Facilitate sprint planning.
	Identify blockers.
	Keep issues small enough to complete.
	Review contribution status.
	Coordinate integration.
	Avoid doing every task personally.
	Ensure every contributor has a meaningful assignment.
	Record decisions in GitHub Discussions or project documentation.
