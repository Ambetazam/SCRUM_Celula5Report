---

## 1. Objetivo

El presente documento tiene como objetivo registrar, de manera objetiva y verificable, las interacciones realizadas dentro del grupo de trabajo relacionadas con la organización, coordinación, desarrollo, revisión y seguimiento de las actividades del proyecto.

La evidencia presentada corresponde a mensajes disponibles en el historial de comunicación del grupo. No se pretende determinar las intenciones personales de los integrantes, sino dejar constancia de las acciones y comunicaciones que pueden observarse directamente.

## 3. Observaciones objetivas

A partir de esta evidencia pueden identificarse las siguientes acciones observables:

1. **Coordinación del repositorio:** se intercambian instrucciones y enlaces relacionados con el repositorio del proyecto.
2. **Uso de herramientas de desarrollo:** se hace referencia explícita a Bash/Git Bash y al proceso de clonación del repositorio.
3. **Actualización del README:** se informa sobre la incorporación de los colaboradores del proyecto en la documentación.
4. **Registro de dificultades técnicas:** se deja constancia de problemas relacionados con la actualización o descarga de cambios mediante Git.
5. **Documentación de problemas:** se comunica que las dificultades experimentadas con `push` fueron incorporadas al backlog/documentación del informe.
6. **Verificación mediante clonación:** se informa que se intentó clonar nuevamente el repositorio para comprobar la disponibilidad de los cambios.
7. **Solicitud de orientación:** ante la persistencia del problema, se solicita apoyo para determinar los pasos siguientes.
8. **Seguimiento de actividades pendientes:** se recomienda revisar las notas existentes para identificar tareas aún pendientes.
