### Evidencia de comunicación y sincronización del repositorio

Durante el proceso de integración de los cambios realizados en el repositorio, se presentó una dificultad relacionada con la actualización y sincronización de una copia bifurcada (*fork*) del proyecto.

En la comunicación entre los integrantes se manifestó inicialmente que, después de realizar el procedimiento de actualización, los cambios esperados no aparecían en el repositorio local. Ante esta situación, se propuso realizar nuevamente el proceso de sincronización y, como alternativa, eliminar el *fork* existente y crear uno nuevo para comenzar el proceso desde cero.

Como parte de las instrucciones proporcionadas para verificar y actualizar las diferentes ramas del repositorio, se indicaron los siguientes comandos:

```bash
git pull origin main
git pull origin develop
git pull
```

También se compartió el enlace correspondiente al repositorio utilizado durante el procedimiento:

`https://github.com/Ambetazam/SCRUM_Celula5Report`

Posteriormente, el integrante informó que había eliminado el repositorio *forkeado*, realizado nuevamente el proceso de *fork* y clonado el repositorio desde cero. Sin embargo, manifestó que los archivos o cambios esperados todavía no aparecían después de realizar el procedimiento.

La conversación evidencia que se realizó un proceso de verificación y sincronización colaborativa del repositorio con el objetivo de garantizar que los cambios desarrollados por los integrantes pudieran ser correctamente incorporados y visualizados en las ramas correspondientes.
