# Create Initial Test Plan

## Objective

Define the initial validation strategy for the Planificador de Menús y Lista de Mercado.

## Test Cases

Create test cases for:

1. Creating a menu plan.
2. Adding a recipe to a day.
3. Assigning a recipe to a meal.
4. Adding multiple recipes.
5. Consolidating ingredients.
6. Subtracting pantry quantities.
7. Generating the shopping list.
8. Marking an item as purchased.
9. Invalid quantities.
10. Invalid recipe references.

## Acceptance Criteria

* [ ] At least one test case exists for each principal operation.
* [ ] Expected results are defined.
* [ ] Invalid input is considered.
* [ ] Tests are documented in the repository.
* [ ] Failed tests are reported through GitHub Issues.
